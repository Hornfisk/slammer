# slammer (redirect)

Redirect stub for `hornfisk.github.io/slammer/` → `hyperfocusdsp.github.io/niner/`.

The Slammer repo was transferred from `Hornfisk/slammer` to `hyperfocusdsp/slammer` on 2026-04-19, then renamed to `hyperfocusdsp/niner` on 2026-04-26 due to a trademark conflict. GitHub redirects repo URLs on transfer + rename, but GitHub Pages does not redirect across user/org boundaries — this repo exists only to serve the Pages redirect page so stale links to the old audio preview URL don't 404.

Source is at [hyperfocusdsp/niner](https://github.com/hyperfocusdsp/niner). Audio samples at [hyperfocusdsp.github.io/niner](https://hyperfocusdsp.github.io/niner/).
